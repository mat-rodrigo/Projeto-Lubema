Este projeto se trata de um conjunto de softwares que tem como objetivo o auxilio de comércios, tendo como principal diferencial o tratamento e mapeamento do estoque
# 📦 Aplicativo de Controle de Estoque

## 📌 Descrição
Este é um aplicativo de controle de estoque que se conecta com a nuvem para permitir o controle da distribuição de produtos em diferentes lojas. O sistema permite:
- Cadastro de produtos com LOT, validade, nome, quantidade e foto.
- Controle de entrada e saída de produtos.
- Alertas para estoque baixo e produtos próximos da validade.
- Relatórios filtráveis e exportáveis em PDF.
- Classificação de produtos por IA a partir da foto.
- Suporte a múltiplas lojas.

## 🎯 Funcionalidades
- 📌 **Entrada e Saída de Estoque**: Registre movimentações de produtos.
- 🔎 **Busca Rápida**: Encontre produtos pelo nome, LOT ou foto.
- 🛑 **Alertas**: Estoque baixo e validade próxima.
- 📊 **Relatórios Detalhados**: Filtros por tempo, nome, quantidade e validade.
- 🏪 **Gestão Multi-loja**: Estoque separado por lojas com relatórios individuais.

## 🏗️ Tecnologias Utilizadas
- **Front-end**: React Native ou Flutter
- **Banco de Dados**: SQLite (offline)
- **Back-end**: Local (sincronização futura opcional)
- **Relatórios**: Gráficos e exportação em PDF
- **Inteligência Artificial**: Classificação de produtos por imagem

## 🚀 Como Executar o Projeto
1. Clone o repositório:
   ```sh
   git clone https://github.com/seu-usuario/estoque-offline.git
   cd estoque-offline
   ```
2. Instale as dependências:
   ```sh
   npm install # Para React Native
   flutter pub get # Para Flutter
   ```
3. Execute o aplicativo:
   ```sh
   npm start # React Native
   flutter run # Flutter
   ```
